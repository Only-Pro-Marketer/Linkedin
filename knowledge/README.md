# Knowledge files

These markdown files are the writing playbooks Claude reads (in its cached
system prompt) when drafting posts, comments, replies, plans and profile
rewrites. See `loader.py` for which feature uses which file.

## Source and license

Copied from [linkedin-skills](https://github.com/sergebulaev/linkedin-skills)
v1.0.44 by Serge Bulaev, released under the MIT License (see `LICENSE` in this
folder). `hook-classification.md` is that project's
`skills/linkedin-hook-extractor/references/classification-rules.md`, renamed.

Not copied: the voice-profile template (this app uses `soul/soul.md`) and the
publishing/image-service integrations.

Many numbers in these files are vendor data or practitioner claims (MagicPost,
AuthoredUp, Co.Actor, internal corpora). Treat them as directional guidance,
not verified facts.
